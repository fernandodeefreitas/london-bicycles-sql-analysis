# London Bicycles SQL Analysis

## Overview
SQL analysis of the London Bicycle Hire public dataset using Google BigQuery.

## Dataset
- **Source:** `bigquery-public-data.london_bicycles`
- **Tables:** cycle_hire, cycle_stations

## Objectives
- Analyse trip duration patterns
- Identify busiest stations
- Explore ride behaviour across London

## Tools
- Google BigQuery (SQL)
- Google Data Studio (visualisation)
